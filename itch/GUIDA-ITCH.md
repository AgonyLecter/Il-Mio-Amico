# Pubblicare "Il Mio Amico" su itch.io

Vai su https://itch.io/game/new e compila così.

## Campi della pagina

| Campo | Cosa mettere |
|---|---|
| **Title** | `Il Mio Amico` |
| **Project URL** | `il-mio-amico` |
| **Short description or tagline** | `A cute game. I promise.` |
| **Classification** | Games |
| **Kind of project** | **HTML** |
| **Release status** | Released |
| **Pricing** | No payments, oppure "Donation" / "Pay what you want" con minimo 0 (a tua scelta) |

## Upload

1. Clicca **Upload files** e carica **`il-mio-amico-itch.zip`**.
2. Spunta **"This file will be played in the browser"**.

## Embed options

| Opzione | Valore |
|---|---|
| Embed in page | Manually set size → **960 × 540** |
| Mobile friendly | ✅ sì, Orientation: **Landscape** |
| Automatically start on page load | ❌ no (meglio "Click to launch": serve per audio e schermo intero) |
| Fullscreen button | ✅ sì |
| Enable scrollbars | ❌ no |

## Details

- **Description**: incolla `description_en.txt`, poi una riga di separazione, poi `description_it.txt`.
- **Genre**: Interactive Fiction (in alternativa: Visual Novel)
- **Tags** (massimo 10): `horror`, `psychological-horror`, `pixel-art`, `cute`, `creepy`, `multiple-endings`, `story-rich`, `short`, `singleplayer`, `virtual-pet`
- **AI generation disclosure**: itch lo chiede. Rispondi tu in modo onesto in base a come hai creato il gioco.
- **Custom noun**: lascia vuoto
- **Community**: Comments (consigliato)
- **Visibility**: prima *Draft*, controlla che tutto funzioni, poi *Public*

## Metadata (sezione "Edit metadata" dopo il salvataggio)

- **Platforms**: HTML5 (giocabile nel browser), Android, iOS (via browser)
- **Languages**: English, Italian
- **Inputs**: Mouse, Keyboard, Touchscreen
- **Average session**: About a half-hour
- **Accessibility**: Subtitles (tutto il testo è scritto)
- **Content disclaimer**: segnala contenuti violenti/sangue (Mature content / Violence). PEGI 16.
